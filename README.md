# Srikar 3D Portfolio

A cinematic React + Three.js portfolio for Nemuri Srikar Goud, designed around a scroll-driven space journey.

## Highlights

- Scroll-driven WebGL background: Earth → orbit/deep space → black hole
- Real Earth texture layers (day/night/cloud/bump/specular) loaded from the referenced Three.js Earth project
- Procedural black-hole scene with an animated accretion disk and star field
- Cursor-follow interaction and hover states
- Project galleries using screenshots from ShopMyUniform, AI Resume Analyzer, Real-Time Chat and Fairway Forward
- Live project and GitHub source links
- Experience section
- Education section with B.Tech / ECE and CGPA
- Coding platform links: LeetCode, GeeksforGeeks, CodeChef and Take U Forward
- 12 certificate previews with original PDF links
- Resume and LinkedIn links
- Responsive layout + reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```
